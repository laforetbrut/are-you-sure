# FAQ

**Is this a joke?**
Yes. Are you sure you want to install it?

**Does the server need the mod?**
No. It is client-side only and works on vanilla, Forge and NeoForge servers.

**Can I disable it for a moment?**
Remove the jar. There is intentionally no off switch.

**Why does the game keep running while I type the captcha?**
Because it is funnier that way.

**Does it block walking, jumping or opening the inventory?**
No. It covers interactions: breaking, attacking, using, placing, opening containers, talking to
villagers, pick-block.

**Can I use it in a modpack or a video?**
Yes, the mod is MIT licensed.
